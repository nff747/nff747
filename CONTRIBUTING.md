# Contributing to nff747 GitHub Profile

Contributions, suggestions, and aesthetic enhancements to the profile layout, contribution graph visualizers, or automation scripts are welcome!

## Running the SVG Generator

```bash
python3 generate_contribution_svg.py
```

## How to Contribute

1. Fork the repo and create a branch (`git checkout -b feat/profile-enhancement`).
2. Test your changes locally.
3. Submit a Pull Request.
